ATELIER ARENA / FORMAT V1

Face technique

Le contrat que lit l’agent pour fabriquer un assemblage 3D animé, vérifiable avant son insertion dans KREO.

01 / FICHIERS

Un lot, pas un projet

kreo.asset v1 porte des objets à ajouter. Le brief est copié ou transmis par l’auteur ; aucune scène n’est hébergée ici.

02 / 3D & MOUVEMENT

Maillages & clés

Primitives ou sommets/faces. Pivots imbriqués et pistes position, rotation, échelle. En boucle, en aller-retour ou une fois.

03 / MODE AGENT

Valider avant retour

Dans le dépôt connecté, lance la validation depuis le terminal d’Arena. Sans dépôt, renvoie le JSON dans la conversation.

node tools/kreo-atelier.mjs validate creation.kreo-asset.json
